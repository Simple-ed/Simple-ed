# Cold Call Scripts

## Opening Framework

### Pattern Interrupt Opener
```
"Hi {{first_name}}, this is [Your name] with [Company].
Did I catch you at a bad time?"

[If yes]: "When would be better for a quick 2-minute call?"
[If no]: Continue to reason for call
```

### Permission-Based Opener
```
"Hi {{first_name}}, this is [Your name]. We've never spoken before.
Do you have 30 seconds for me to tell you why I'm calling,
and you can decide if we should keep talking?"
```

---

## Reason for Call

```
"The reason I'm calling is we help [target role] at [company type]
who are struggling with [pain point].

Does that resonate at all with what you're seeing at {{company}}?"
```

---

## Discovery Questions

1. "What's your current approach to [problem area]?"
2. "What's working well? What's not?"
3. "What happens if this doesn't get solved?"
4. "Who else is involved in decisions like this?"
5. "What would success look like for you?"

---

## Handling Objections

### "I'm not interested"
```
"I understand. Quick question before I let you go -
is it because [pain point] isn't a priority, or
you've already solved it another way?"
```

### "Send me some information"
```
"Happy to. So I send you something relevant -
what specifically would you want to see?"
```

### "We already have a solution"
```
"That's great you're already addressing this.
Out of curiosity, what made you choose that approach?
Is it working the way you hoped?"
```

### "I don't have time"
```
"Totally understand. Would it make sense to
schedule 15 minutes later this week when it's
more convenient?"
```

### "What's this going to cost?"
```
"It depends on your situation. To give you an accurate idea,
I'd need to understand more about [specific need].
Can we schedule a quick call to explore that?"
```

---

## Closing for Next Steps

```
"Based on what you've shared, it sounds like we should
talk more. I have [day] at [time] or [day] at [time] -
which works better for a 30-minute call?"
```

---

## Voicemail Script (Under 30 seconds)

```
"Hi {{first_name}}, this is [Your name] with [Company].

I'm calling because we help [target role] with [pain point]
and I had a quick idea for {{company}}.

My number is [phone number]. Again, that's [phone number].

Looking forward to connecting."
```

---

## Call Metrics to Track

- Dials per hour
- Connect rate (conversations / dials)
- Conversation to meeting rate
- Best times/days for connects
- Objections heard (to improve scripts)
