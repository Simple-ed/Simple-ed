# LinkedIn Outreach Sequence

## Connection Request Templates

### Template 1: Mutual Interest
```
Hi {{first_name}}, I noticed we're both in the [industry] space.
Would love to connect and share insights. - [Your name]
```

### Template 2: Content-Based
```
Hi {{first_name}}, saw your recent post about [topic] -
great insights. Would love to connect.
```

### Template 3: Direct
```
Hi {{first_name}}, I help [target role] at [company type]
with [outcome]. Thought it'd be worth connecting.
```

---

## Post-Connection Sequence

### Message 1: Thank You (Day 0 - After Accept)
```
Thanks for connecting, {{first_name}}!

I'm curious - what's the biggest challenge you're
facing with [relevant topic] right now?
```

### Message 2: Value Add (Day 3)
```
Hey {{first_name}}, thought you might find this useful -
[link to relevant resource/article/case study].

Let me know if it's helpful!
```

### Message 3: Soft Pitch (Day 7)
```
{{first_name}}, based on what I've seen at {{company}},
I have a few ideas that might help with [pain point].

Worth a 15-min call to explore?
```

### Message 4: Final Touch (Day 14)
```
Hi {{first_name}}, just checking in one last time.

If [solving pain point] becomes a priority,
happy to chat whenever timing works.
```

---

## LinkedIn Best Practices

1. **Warm up your profile** - Post content, engage with others first
2. **Personalize connection requests** - Generic = ignored
3. **Don't pitch immediately** - Build rapport first
4. **Engage with their content** - Like/comment before reaching out
5. **Keep messages short** - LinkedIn is conversational
6. **Voice notes** - Stand out with personalized voice messages
7. **Connection limits** - Stay under 100 requests/week to avoid restrictions
