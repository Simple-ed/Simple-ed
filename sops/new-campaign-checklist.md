# New Campaign Launch Checklist

## Pre-Launch (1-2 Days Before)

### 1. Define Campaign Goals
- [ ] Target number of prospects
- [ ] Expected meetings to book
- [ ] Revenue goal
- [ ] Timeline (start/end dates)

### 2. ICP Validation
- [ ] ICP document updated
- [ ] Clear on who we're targeting
- [ ] Clear on who we're NOT targeting
- [ ] Have relevant case studies/proof points

### 3. Build Prospect List
- [ ] Source prospects from relevant platforms
- [ ] Minimum 200-500 prospects for meaningful test
- [ ] Verify all email addresses
- [ ] Add personalization data
- [ ] Remove duplicates, competitors, existing customers
- [ ] Import to outreach tool

### 4. Create Messaging
- [ ] Write email sequence (3-5 emails)
- [ ] Write LinkedIn messages (3-4 touches)
- [ ] Write call script if applicable
- [ ] A/B test variations ready
- [ ] Get feedback/review from others if possible

### 5. Technical Setup
- [ ] Email domain warmed up (2+ weeks for new domain)
- [ ] SPF, DKIM, DMARC configured
- [ ] Sending limits set appropriately
- [ ] Calendar booking link works
- [ ] CRM/tracking ready

---

## Launch Day

### 6. Soft Launch
- [ ] Start with small batch (20-50 prospects)
- [ ] Monitor deliverability
- [ ] Check for bounces/issues
- [ ] Verify emails landing in inbox (not spam)

### 7. Scale Up
- [ ] If soft launch successful, increase volume
- [ ] Ramp up gradually (don't send 500 emails day 1)
- [ ] Typical ramp: Day 1: 20, Day 2: 40, Day 3: 60...

---

## Ongoing (Daily/Weekly)

### 8. Monitor & Optimize
- [ ] Track open rates (target: 40%+)
- [ ] Track reply rates (target: 5%+)
- [ ] Track meeting conversion
- [ ] Identify winning messages
- [ ] Kill underperforming variants
- [ ] Refresh messaging every 2-4 weeks

### 9. List Maintenance
- [ ] Remove bounces immediately
- [ ] Remove unsubscribes immediately
- [ ] Update prospect statuses
- [ ] Add new prospects to keep pipeline full

---

## Campaign Debrief (End of Campaign)

### 10. Analysis
- [ ] Total prospects contacted
- [ ] Total replies
- [ ] Total meetings booked
- [ ] Total opportunities created
- [ ] Total revenue generated
- [ ] Cost per meeting
- [ ] What worked well?
- [ ] What didn't work?
- [ ] What will we do differently next time?

---

## Red Flags to Watch

Stop/pause campaign if:
- Bounce rate > 5%
- Spam complaints received
- Open rate < 20%
- Reply rate < 1% after 200+ sends
- Multiple people asking "how did you get my info"
