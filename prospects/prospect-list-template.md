## List Hygiene Checklist

Before launching campaign:
- [ ] Emails verified (use NeverBounce, ZeroBounce, etc.)
- [ ] No duplicates
- [ ] Matches ICP criteria
- [ ] Has personalization data
- [ ] Removed competitors
- [ ] Removed existing customers
- [ ] Removed previous unsubscribes/bounces

## Prospect Status Definitions

| Status | Definition |
|--------|------------|
| New | Not yet contacted |
| Contacted | First touch sent |
| Engaged | Opened/clicked/replied |
| Meeting Booked | Call scheduled |
| Qualified | Good fit, opportunity created |
| Disqualified | Not a fit |
| Not Now | Timing not right, follow up later |
| Unresponsive | Completed sequence, no response |
