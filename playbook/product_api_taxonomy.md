# Daloopa Product — API & Taxonomy

---

## Daloopa API

Daloopa API delivers best-in-class data via **8 endpoints**, each with different functions. Users can call all data points and metadata currently offered in the core product into their systems.

### Key Features:
- **8 API Endpoints** with different functions
- **2 Webhooks** — notify users whenever latest actuals are published (real-time update speed)
- Programmatic data ingestion
- All data points and metadata from core product available

### Taxonomy
Standardized way to fetch similar datapoints across companies, enabling:
- Industry analyses
- Comp analyses
- **1,200+ standardized metrics** across:
  - Income statements
  - Balance sheets
  - And more

### Additional Capabilities (Beta):
- **Document Access** — programmatic access to source documents
- **Keyword Search** — search across filings
- **MCP (Model Context Protocol)** — create AI agent integrations based on API documentation

## Key Selling Points for Quant/Systematic Teams:
1. **API delivery** — no manual downloads, direct pipeline integration
2. **Webhooks for real-time updates** — know the moment new actuals are published
3. **1,200+ standardized metrics** via Taxonomy — consistent field names across companies
4. **Point-in-time data** — critical for backtesting without look-ahead bias
5. **Programmatic ingestion** — fits into existing data infrastructure
6. **MCP integration** — for teams building AI/LLM-powered research tools
