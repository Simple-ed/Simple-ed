# Daloopa Product — MCP (Model Context Protocol)

---

## What is Daloopa MCP?

Daloopa's MCP allows best-in-class fundamental data to be flexibly and securely accessed by Large Language Models (LLMs) for use in various AI applications.

### How It Works:
- MCP enables LLMs to communicate effectively with Daloopa's database
- Gives systematic instructions to the client's LLM on how to query and pull data
- LLMs efficiently digest Daloopa's vast fundamental database without overloading their system
- AI agents won't spend time generating inaccurate data — focus on generating actionable insights instead
- Saves clients significant time and resources

### Key Integrations:
- **Claude (Anthropic)** — full MCP integration with demo available
- **OpenAI / ChatGPT** — API-based integration with documentation
- Works with any LLM that supports MCP

### Key Selling Points:
1. **LLM-native data access** — no manual data prep for AI workflows
2. **Secure and structured** — LLM gets systematic instructions, not raw dumps
3. **No hallucination on financial data** — AI agents pull verified Daloopa data instead of generating numbers
4. **Saves engineering time** — no need to build custom data connectors for AI tools
5. **Keyword Search (beta)** — search across filings programmatically

## MCP vs. API

| Feature | MCP | API |
|---|---|---|
| Primary User | AI/LLM applications | Data pipelines / programmatic systems |
| Integration | Claude, OpenAI, any LLM | REST API endpoints |
| Best For | AI-powered research, natural language queries | Systematic data ingestion, backtesting |
| Output | Conversational / structured responses | Raw data (CSV, JSON) |
| Use Case | "Pull TSLA revenue trends" in natural language | Automated pipeline pulling 4,000 tickers nightly |
