# Daloopa Cold Outbound Email Drafts

A collection of cold outbound email templates, sequences, and frameworks for Daloopa's sales outreach.

## About Daloopa

Daloopa is an AI-powered financial modeling copilot that automates the extraction and delivery of fundamental data from company filings directly into analysts' Excel models. Founded in 2019, Daloopa has raised $40M and serves hedge funds, private equity firms, mutual funds, and investment banks.

### Core Value Propositions
- **Save hours per model update** -- eliminates manual data entry from earnings releases, SEC filings, and investor presentations
- **4-10x more data points per ticker** than the next leading fundamental data provider
- **13 years of historical data** sourced from SEC filings, press releases, transcripts, and all public filings
- **One-click Excel updates** via an Excel add-in that links directly to AI-extracted data
- **Source verification** -- every data point hyperlinked to the original filing for instant audit

## How to Use

1. **Identify your prospect's persona** using `icp.md`
2. **Pick a template** from `templates/` matching the persona
3. **Personalize** using the framework in `personalization.md`
4. **Choose a subject line** from `subject-lines.md`
5. **Queue follow-ups** from `sequences/follow-up-sequences.md`
